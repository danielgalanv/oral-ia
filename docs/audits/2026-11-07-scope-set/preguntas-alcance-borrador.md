# Borrador del asistente para el conjunto de alcance (a revisar y corregir por el docente)

Lo he redactado yo imitando cómo escribe un alumno. Cámbialo, borra lo que no valga y añade lo que falte; **la etiqueta es el grupo** (como en `preguntas-alcance.md`). Lo que no corrijas lo daré por bueno para medir el filtro. Las del grupo 4 son mi suposición de lo que el material NO trata: confírmalo o muévelo al grupo 1.

## 1. Preguntas directas de estudio → debe responderse
- que es la elicitacion de requisitos
- ¿Para qué sirve validar los requisitos si ya los ha escrito el cliente?
- diferencia entre requisito funcional y no funcional con ejemplo
- ¿Qué información debería tener la matriz de trazabilidad?
- ¿Por qué un requisito tiene que ser verificable?

## 2. Seguimientos → debe responderse
- Anterior: ¿Qué es la trazabilidad de requisitos? → Seguimiento: ¿y eso para qué me sirve en la práctica?
- Anterior: ¿Qué técnicas hay para elicitar requisitos? → Seguimiento: ¿cuál es mejor si el cliente no sabe lo que quiere?
- Anterior: ¿Qué es un requisito no funcional? → Seguimiento: ponme otro ejemplo
- Anterior: ¿Qué diferencia hay entre validar y verificar? → Seguimiento: no lo entiendo, ¿puedes explicarlo más fácil?
- Anterior: ¿Qué es un caso de uso? → Seguimiento: ¿y cómo se relaciona con los requisitos funcionales?

## 3. El alumno comprueba su propia comprensión → debe responderse
- Creo que un requisito no funcional es lo que el sistema hace, como "el sistema permite pagar con tarjeta". ¿Es correcto?
- Entiendo que validar es comprobar que el sistema está bien programado. ¿Voy bien?
- Mi resumen: la trazabilidad sirve para saber qué requisito origina cada parte del diseño y de las pruebas. ¿Está bien?
- ¿Es verdad que la elicitación consiste solo en hacer entrevistas al cliente?
- Pienso que "el sistema debe ser rápido" es un buen requisito porque se entiende. ¿Es así?

## 4. Tema de la asignatura pero que el material NO cubre → debe decir "el material no lo trata"
- ¿Qué es el modelo de Kano y cómo se usa para priorizar requisitos?
- ¿Cómo se aplica QFD (despliegue de la función de calidad) a los requisitos?
- ¿Cómo se configura DOORS para gestionar la trazabilidad?
- ¿Qué es la plantilla Volere y qué apartados tiene?
- ¿Cómo se estiman los puntos de función a partir de los requisitos?
