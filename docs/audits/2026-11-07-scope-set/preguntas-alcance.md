# Conjunto de preguntas para medir el filtro de alcance (a rellenar por el docente)

Escribe unas 5 preguntas por grupo, tal como las escribiría un alumno (con sus faltas de precisión, abreviaturas, etc.). **La etiqueta es el grupo**: lo que pongas bajo "debe responderse" se espera que se responda; bajo "debe rechazarse", que se rechace. El material son 9 documentos (requisitos, procedimiento, procesos, ágil, modelos, testing, NASA, Sommerville y SWE-055) más, en v3, el estándar IEEE 830 y el capítulo STSE.
