# Normal reviewed-unit binding — mandatory T021 implementation contract

This binding is separate from draft preview. It must never call DraftCurriculum
render_preview for a participant or turn a model sentence into a trusted value.
The actual83course units remain draft, activity draft, participant entry denied.

An explicit application-owned runtime dependency is scoped to one database engine
and activity. No HTTP body, URL, pseudonymous code or environment credential can
create or select that dependency. Ordinary app construction and all existing
guided/defense routes retain their defaults. The new path is only self-study in
non-protected explanation/doubt modes; protected practice and defense retain
their existing disclosure controls and do not expose solutions to this path.

For each turn, rebuild the catalog from current published units authorized for
the authenticated session/activity. Infer roots and teaching roles from existing
typed relations: didactic_cause/process, rephrases, examples, comparisons, next;
validate every referenced unit, goal and role. Cross-goal comparison relations
must bind a current published secondary root and primary-goal teaching units.
Question feedback is an explicit current comparison reference. No unit is
published or marked reviewed by this process. Existing G1 checks remain required.

The existing StudyIntentInterpreterAgent proposes only canonical references/acts.
Goal-title reference projection may rename labels reversibly; source/unit/question
identities and real input are unchanged. Never persist raw model text, prompt or
claim_quote in participant traces. Persist only existing bounded procedural facts,
contract/status/IDs, with the normal privacy lifecycle. No grade/mastery field.

Convert an accepted structural proposal into one to three reviewed unit references
and an allowed versioned template. Reconstruct through the existing reviewed-unit
adapter, grounding/coherence/non-disclosure verifiers and final T090 gate. Receipt
or greeting prefixes, if required, need explicit closed templates/policy approval;
they cannot be arbitrary slots. Revalidate resources after awaited work. Only an
approved output can update goal/pair/pending-question state through existing CAS
inside the turn transaction. Cancellation, stale state, withdrawal or denied
authorization must not advance the teaching state or publish candidate text.

Keep the existing10000ms guided budget unchanged by default. Any explicit new
runtime budget must be bounded/versioned, respect existing individual agent
maxima and session duration, and be disclosed in turn metadata. The candidate
interpreter's32s contract does not silently enlarge ordinary guided turns.

Positive integration fixtures must be explicitly fictional and use normal teacher
publication/authentication APIs; they do not demonstrate review or utility of the
real course. Required negatives include draft/retired/foreign units, inactive
source, foreign engine/activity/session, protected mode, cancellation, stale CAS,
denied T090, actual pending-question binding, no raw trace/credential leakage,
and unchanged legacy defaults. Real-course review and SC001/G2 remain open.
