# Documentary evidence contract (lab only, v1)

`load_authorized_units()` reads only the 17 already ingested pages from the three unchanged teacher PDFs selected by `corpus.py`. It rechecks each original PDF hash. A unit retains the document hash/version, page identity, exact text offsets and line numbers, or a table bounding box and extracted rows. An adjacent-page join requires an explicit `continues_from_previous` marker and matching document, consecutive page number, and block kind; no real page currently has that marker.

`retrieve_units()` checks every supplied unit against the supplied authorized catalog **before** ranking. It searches all catalog units using current-question terms plus at most two displayed history turns, unless `focus_change=True`. It records selected, omitted-by-budget and unselected candidate IDs, and never splits a unit to fit the budget. The result exposes the full catalog page/document inventory and labels its scope `authorized_ingested_catalog_only_not_complete_course`. Lexical ranking and document diversity are retrieval heuristics, not relevance or entailment proofs.

`MultiPassageReview` locates an exact answer claim and can carry up to five exact source passages and four distinct answer-premise quotes. Structural validation checks original page identities/hashes/spans, witness count/length, explicit inference premises and unresolved disagreement (`unknown`). Fictional examples cannot use literal documentary passages. The record never grants publication. A human or independently validated semantic evaluator must still decide whether the passages jointly support the claim and whether the answer covers the question. If sources disagree, retain both and mark the unresolved claim unknown. Consent, access, T090/T150 and participant runtime remain unchanged.

The real selected catalog currently yields 17 list units and no extracted tables or explicit cross-page joins. Synthetic tests exercise paragraphs, tables and joins. The contract does not claim coverage of the full course, source quality, model correctness or G2/SC001.
