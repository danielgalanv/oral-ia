# Calidad de requisitos de pertinencia contextual

- [X] Tema, propósito, contenido y fuente tienen oráculos separados.
- [X] Referente numérico distingue objeto comparado, comparación y bloqueo anterior.
- [X] Saludo compuesto y cierre con prefijo conservan negación/cita/consentimiento.
- [X] Agotamiento no se diagnostica como permiso ni exige revelar respuestas.
- [X] Capturas y primeras reservas se preservan sin aprobación humana inferida.
