# Revisión humana del paquete: pendiente

16 conversaciones completas por API real y 80 instancias de60 estímulos expuestos. No STT/TTS, no personas participantes. La revisión negativa anterior de D01 permanece histórica; estos sucesores no tienen aprobación humana.

Criterios: saludo y orientación antes de ejemplos; qué/por qué/cómo; tres estrategias distintas; posibilidad/condiciones; referentes y pregunta pendiente; fuentes vigentes; no revelación; elección y efecto real de conservación/cierre/revisión/borrado. Evaluar por separado pertinencia, suficiencia y fidelidad científica: una referencia autorizada no los demuestra.
