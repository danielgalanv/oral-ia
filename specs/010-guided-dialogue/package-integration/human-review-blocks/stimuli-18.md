## programa-pptx / DEV-programa-responsabilidades-definition

Participante: ¿Qué significa organización de una explicación técnica?

ORALIA: Una responsabilidad describe qué hace una parte del programa y qué resultado entrega. En este caso se separan entrada, validación, almacenamiento y salida. Las funciones permiten organizar esas tareas de forma comprensible.

## programa-pptx / DEV-programa-responsabilidades-process

Participante: Explícame paso a paso organización de una explicación técnica.

ORALIA: Para exponer el diseño, primero explica el objetivo del programa y sus entradas. Después recorre un caso aceptado: recibir, validar, guardar y confirmar. A continuación recorre un rechazo o fallo de escritura. Finalmente declara qué hace cada parte y qué garantías no ofrece el ejemplo.
