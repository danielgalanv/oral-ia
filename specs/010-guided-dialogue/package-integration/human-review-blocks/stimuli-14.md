## programa-docx / DEV-programa-salida-process

Participante: Explícame paso a paso mensajes comprensibles.

ORALIA: Primero, identifica el resultado que recibió el flujo principal. Después, elige un mensaje fiel a ese estado. Por último, indica una acción posible: completar el campo, escribir una cantidad admitida o comprobar el destino de guardado. No cambies los datos ni repitas el guardado por el mero hecho de mostrar un aviso.
